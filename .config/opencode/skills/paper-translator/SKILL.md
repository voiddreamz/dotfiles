# 论文翻译与解读

## 触发场景
- 用户要求读论文、翻译论文、总结论文
- 用户分享 arXiv 链接或论文 PDF
- 用户问"这篇论文说了什么"

## 工作流程

### 1. 获取论文内容
- 优先使用 arxiv MCP 工具 (`arxiv_search`, `arxiv_read_paper`, `arxiv_get_metadata`)
- 若论文不在 arXiv，使用 `webfetch` 获取在线版本
- 对大论文，分章节处理避免上下文溢出

### 2. 结构化解读
按以下顺序呈现：

**📋 论文卡片**
- 标题（中英对照）
- 作者、机构、发表日期
- arXiv ID / DOI
- 一句话核心贡献

**🎯 研究动机**
- 解决了什么问题？为什么重要？
- 前人方法有什么不足？

**💡 核心方法**
- 技术路线（用通俗比喻解释）
- 关键创新点（与之前工作的本质区别）
- 避免深奥术语堆砌——每个术语第一次出现时附带简短解释

**📊 实验与结论**
- 主要实验结果（定量数据）
- 结论的可靠性和局限性
- 作者自述的不足

**🔮 我的评价**（若能判断）
- 方法的巧妙之处
- 潜在问题或遗漏
- 与相关工作的关系

### 3. 翻译规则
- 专业术语首次出现保留英文原文，如 "attention mechanism (注意力机制)"
- 公式符号保留原文（LaTeX 格式）
- 图表描述用中文
- 保持学术严谨性，不擅自简化或曲解
- 如果用 translator MCP 翻译，注明翻译工具

## 输出语言
- 默认中文输出，保留英文术语注释
- 用户可指定目标语言
